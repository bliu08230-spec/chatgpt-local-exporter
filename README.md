# ChatGPT 对话存档

免费导出ChatGPT网页版聊天记录，支持Edge和Chrome。
全部在本机处理，无需API Key，不向开发者上传聊天内容。

## 下载

[点击下载最新版](https://github.com/bliu08230-spec/chatgpt-local-exporter/releases/latest)

进入页面后，在Assets中下载带版本号的扩展ZIP，
不要下载Source code。

## 安装

1. 解压扩展ZIP到固定文件夹。
2. 打开 edge://extensions 或 chrome://extensions。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择包含manifest.json的文件夹。
5. 打开自己的ChatGPT对话，点击扩展图标使用。

## 功能

- 单条对话支持Word，图片嵌入文档，可离线查看。
- 支持Markdown、HTML、JSON、TXT及ZIP。
- 长对话Word自动分卷。
- 支持多条对话批量导出Markdown和JSON。

## 更新

下载新版并更新本地扩展文件，重新加载扩展，
关闭旧导出页、刷新ChatGPT网页后再使用。
通过GitHub下载安装的扩展需要手动更新。
